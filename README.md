# Lombard 槓桿試算器

本金投入債券／基金組合 → 循環質押放大部位 → 評估現金流與 margin call 風險。

## 兩種本金性質

| 模式 | 情境 | 主要指標 |
|---|---|---|
| **自有資金（無成本）** | 本金不用還本付息 | 自有資金年報酬率 |
| **房貸借出（有成本）** | 本金來自房貸，需還本付息 | 房貸覆蓋率（已扣本金攤還＋利息） |

選「自有資金」時仍可另外填入一筆房貸金額，比較配息能否覆蓋；填 0 則只看報酬率。

## 功能

| 區塊 | 內容 |
|---|---|
| ① 部位結構 | 原始層～第六層的總部位、總借款、擔保品、槓桿倍數，可展開逐層明細 |
| ② 現金流 | 自有資金報酬率／房貸覆蓋率、扣房貸後結餘、打平所需最低配息率 |
| ③ 風險評估 | 額度使用率、距通知／追繳線可跌幅度、**匯率×債價雙因子矩陣**、淨值侵蝕存活年數、升息壓力測試 |
| ④ 配息率敏感度 | 折線圖，房貸年繳為水平線，曲線在線上即為可覆蓋 |
| ⑤ 輸出 PDF | 一鍵產生繁體中文 PDF 摘要報告 |

## 計算邏輯

**可動用額度成數** = 加權 LTV × 錯幣折扣 × 額度動用比例

其中加權 LTV = 債券比重 × 債券 LTV + 基金比重 × 基金 LTV。

**額度使用率**（margin call 的判斷基準）：

```
使用率 = 借款金額 ÷ (擔保品市值 × LTV × 錯幣折扣 × 額度動用比例)
```

| 使用率 | 狀態 |
|---|---|
| 達 95% | 啟動通知 |
| 達 100% | 須補繳 |

兩條線都可在側邊欄調整。「擔保品還能跌多少」即由使用率距離該條線的幅度推得。

**層次結構**：

| 層次 | 內容 |
|---|---|
| 原始層 | 自有本金買入的債券，已設質但尚未借款 |
| 第 N 層 | 用第 N−1 層的額度借出、買入並設質的債券 |

第一層～第六層皆可在側邊欄自由勾選（原始層固定顯示，作為不槓桿的對照基準）。
每層借款 = 上一層買入金額 × 可動用額度成數 × 該層動用比例；層數趨近無限時使用率收斂到 100%。

**三個「動用」參數的差別**（最容易搞混的地方）：

| 參數 | 誰決定 | 影響 | 調低的效果 |
|---|---|---|---|
| 額度動用比例 | 銀行 | 額度公式的分母，追繳線跟著移動 | 使用率**上升** |
| 每層實際動用 | 你 | 只影響借多少，追繳線不動 | 使用率**下降** |
| 最後一層動用 | 你 | 同上，但只作用在最後一層 | 使用率**下降** |

以第二層、本金 1,000 萬為例：額度動用比例 90%→80% 使用率由 81.3% 升到 **84.1%**；
每層實際動用 100%→80% 則降到 **69.0%**。

**降低使用率的兩個可控參數**：

- **最後一層動用額度**：設 0% 即「最後一層只設質、不動用額度」，額度留著當緩衝（數值上等同少建一層）；設 50% 等中間值可模擬部分動用
- **追加設質**：客戶名下其他已持有、額外設質進擔保池的債券，只增加擔保品，不增加借款與配息

**匯率風險**：錯幣結構下擔保品與貸款幣別不同，匯率變動會直接折損擔保品價值，
與債券價格下跌為**相乘**關係：

```
匯率折損率 = 1 − 評估匯率 ÷ 建倉匯率
觸發條件   = 借款 = 門檻 × 可動用額度成數 × 部位 × (1−債價跌幅) × (1−匯率折損率)
```

側邊欄以實際匯率報價輸入（幣別對、建倉匯率、評估匯率、情境間距），
「評估匯率」套用到整份風險評估；雙因子矩陣自建倉匯率往下依情境間距列出 5 檔報價，
例如 USD/TWD 31.00 / 30.50 / 30.00 / 29.50 / 29.00。

**房貸年繳**採本息均攤，利率固定。

## 安裝與執行

```bash
pip install -r requirements.txt
streamlit run lombard_mortgage_app.py
```

## 部署到 Streamlit Community Cloud

1. 將本 repo 推到 GitHub
2. 到 [share.streamlit.io](https://share.streamlit.io) 新增 app，主檔案選 `lombard_mortgage_app.py`
3. `requirements.txt` 與 `packages.txt` 會自動被讀取

> `packages.txt` 裡的 `fonts-noto-cjk` 是 **PDF 中文字型**用的，
> 沒有這一行雲端產出的 PDF 中文會變空白。

## PDF 中文字型

程式會依序尋找可用字型，找到任何一個即可：

| 環境 | 來源 |
|---|---|
| 專案自備 | `fonts/NotoSansTC-Regular.ttf` 或 `fonts/msjh.ttc` |
| Streamlit Cloud / Linux | `packages.txt` 安裝的 `fonts-noto-cjk` |
| Windows | 微軟正黑體 `msjh.ttc`、細明體 `mingliu.ttc` |
| macOS | PingFang、STHeiti、Arial Unicode |

都找不到時 app 會顯示提示，其餘功能不受影響。

## 模型假設與限制

- 本金來自房貸，投資部位自有資金為 0，實質風險由房屋淨值承擔
- 配息率視為穩定現金流，未計入債券價格波動、提前買回、違約風險
- 未計入匯率損益。錯幣折扣是銀行對匯率風險的定價，不等於投資人沒有風險
- 未計入海外所得最低稅負、信託／保管費、基金手續費
- 房貸為本息均攤、利率固定；Lombard 利率實務上為浮動
- 債券「持有到期還本」僅保原幣本金，不保台幣本金
- 長年期間債券需再投資數輪，存在再投資風險
- **基金質借成數實務上常低於債券**，請先與授信單位確認後再調整參數
